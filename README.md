# 플루바 마켓 매물 이상형 월드컵

플루바 직거래 마켓의 판매중 매물로 진행하는 이상형 월드컵입니다.
파일 하나로 동작하며 별도 빌드나 서버가 필요 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.
GitHub Pages로 배포하면 `https://<아이디>.github.io/<저장소>/` 로 접속됩니다.

## 데이터

| 항목 | 값 |
|---|---|
| 매물 | 263건 |
| 분류 | 트랙터 220 / 콤바인 33 / 이앙기 10 |
| 실사진 | 260건 (99%) |
| 갤러리(2장 이상) | 194건 |
| 총 사진 | 840장 |
| 기준일 | 2026년 9월 17일 |

판매 상태가 `ONSALE`이고 승인 상태가 `APPROVAL`인 매물만 포함되어 있습니다.
가격·연식·사용시간이 명백한 입력 오류인 4건은 제외했습니다.

- 트랙터: 300만 ~ 3억원
- 콤바인: 300만 ~ 2억원
- 이앙기: 200만 ~ 5,000만원
- 사용시간 1 ~ 20,000시간, 제작년도 1998 ~ 2026

전화번호와 유저 ID 등 개인정보 컬럼은 포함하지 않았습니다.

사진이 없는 매물 3건: TYM T76(2024), 존디어 5420(2006), TYM T552(2006).

## 기능

- 종류 → 브랜드 → 연식 → 가격대 조건으로 후보 좁히기
  - 브랜드·연식·가격대는 모두 **여러 개 동시 선택** 가능 (OR 조건)
  - 가격대: 2천만원 이하 / 2~4천만원 / 4~7천만원 / 7천만~1억 / 1억 이상
  - 아무것도 안 고르면 전체, "전체" 버튼을 누르면 해당 조건이 초기화됩니다
  - 매물이 0대인 구간은 비활성화 (단, 이미 고른 구간은 해제할 수 있게 유지)
  - 종류를 바꾸면 브랜드·연식·가격대 선택이 모두 초기화됩니다
- 조건에 맞는 매물 수에 따라 라운드 자동 결정 (8 / 16 / 32강)
- 가격이 비슷한 매물끼리 대진 편성
- 우승 매물 사진 갤러리 — "매물 전체 이미지 보기"
  (좌우 스와이프, 양쪽 화살표, 현재 장수 표시, 하단 썸네일)
- 유사 매물 추천 및 상세페이지 연결
- 매물 등록 CTA (UTM 포함)

## 레이아웃

대결 화면은 **모든 화면 크기에서 두 장을 가로로 나란히** 배치합니다.
모바일에서 세로로 쌓이면 두 매물을 동시에 볼 수 없어 비교가 어렵기 때문입니다.

- 799px 이하: 가운데 VS 구분선 34px, 카드 내부 여백·글자 크기 축소,
  사양 항목은 라벨과 값을 위아래로 배치
- 359px 이하: 구분선 24px, 여백 추가 축소
- 800px 이상: 기존 데스크톱 레이아웃 (구분선 64px)

카드 높이는 양쪽이 항상 같고, 작업기·옵션 칩은 카드 아래쪽에 고정되어
한쪽에만 칩이 있어도 사양 정보 줄 위치가 맞습니다.

## 우승 화면 갤러리

우승 매물 카드 하나 안에 사진 갤러리와 매물 정보가 함께 들어갑니다.
카드 위쪽이 스와이프 갤러리, 그 아래 "매물 전체 이미지 보기" 라벨과 썸네일,
그 아래 브랜드·모델·가격·사양이 이어집니다.

- 손가락으로 좌우 스와이프 (CSS scroll-snap 기반, 한 장씩 딱 맞게 멈춤)
- 사진 양옆에 화살표 버튼 — 스와이프 가능하다는 신호이자 PC에서의 조작 수단
  (첫 장에서는 왼쪽, 마지막 장에서는 오른쪽 화살표가 흐려집니다)
- 오른쪽 아래 `1 / 5` 형태의 장수 표시
- 썸네일을 누르면 해당 사진으로 바로 이동
- 라벨 옆에 "좌우로 밀어서 넘기세요" 안내 문구

사진이 1장뿐인 매물은 갤러리가 나타나지 않습니다.

## 데이터 교체

`index.html` 안의 `LISTINGS` 배열만 바꾸면 됩니다.

```js
{
  id: "d124b076",           // 매물 ID 앞 8자
  cat: "트랙터",             // 기계분류
  brand: "대동",
  model: "DXM85CF-C",
  year: 2012,
  hours: 980,
  price: 11000000,          // 원 단위
  opt: "",                  // 옵션
  impl: "로타리,로더",        // 작업기
  imgs: ["https://..."],    // 사진 URL (첫 장이 대표)
  url: "https://market.pluva.kr/open-market/{전체 ID}"
}
```

사진은 정면 → 측면 → 후면 → 운전석 → 앞타이어 → 뒤타이어 → 작업기 → 기타 순으로
정렬되어 있습니다. 같은 사진이 여러 타입에 등록된 경우 파일명 기준으로 한 장만 남깁니다.

## 선택 데이터 수집

`pick()` 함수 안에 GA4 전송 자리가 주석으로 표시되어 있습니다.

```js
gtag('event', 'worldcup_pick', {
  category: '트랙터',
  round: '16강',
  winner_id: '...',
  loser_id: '...'
});
```

시작 화면의 브랜드별 우승 랭킹은 localStorage 기반이라 해당 브라우저에서만 집계됩니다.
전체 집계는 GA4 이벤트로 확인해야 합니다.

## 배포 전 확인 사항

- **`anonymous` 경로 사진 55건** — 비회원 상태로 업로드된 사진입니다.
  전체 263건의 21%로, 2차 활용 근거가 없다고 판단되면 사진 커버리지가 99% → 78%로 떨어집니다.
  법무·기획 확인이 가장 먼저 필요한 항목입니다.
- **판매자가 올린 사진의 2차 활용 근거** (이용약관)
- **중복 매물 1쌍** — 구보다 MR707(`e0fd3703`)이 다른 매물과 사진 파일명 세트가 완전히 동일합니다.
  같은 기계가 두 번 등록됐을 가능성이 있어, 사실상 같은 트랙터끼리 붙는 대진이 나올 수 있습니다.
- **타 플랫폼 스크린샷** — 당근마켓·네이버 화면을 캡처해 매물 사진으로 등록한 판매자가 확인됐습니다.
  (해당 매물은 263건 밖이지만 마켓 상세페이지에는 노출 중)
- **AI 생성 이미지 1건** (`a7578e42`)
- **사용시간 이상치 2건** — 구보다 M9540(17,900시간), 얀마 T48(18,000시간).
  입력 오류로 보이며, 상한을 15,000시간으로 내리면 둘 다 걸러집니다.

## 개발팀 요청 목록

- 유저 판매 농기계 이미지 목록에 Export 기능 추가 (판매 농기계 ID / 타입 / 이미지 URL)
- 매물 목록 Export에 `대표 이미지 URL`, `마력` 컬럼 추가
- 등록 폼 값 검증 — 가격 0원·10만원, 제작년도 `23년` 같은 입력 오류 4건 확인
- 같은 사진을 여러 타입 칸에 중복 등록할 수 있는 문제
- 매물이 삭제돼도 남는 고아 이미지 레코드 정리 (`userSellTractor: null`)

## 참고: 사진 경로가 네 종류

```
/sell-tractors/{유저ID 또는 anonymous}/{업로드ID}/{파일명}
/own-tractors/{...}                          ← 플루바 자체 재고
/product-image/image/{...}                   ← 구버전
/user-sell-tractor-image/image/{...}         ← 구버전 및 후처리본(-poke, _poked)
```

파일명에 한글·공백·괄호가 들어가는 경우가 있어 URL 인코딩이 필요합니다.
