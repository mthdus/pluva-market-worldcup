# 플루바 마켓 매물 이상형 월드컵

플루바 직거래 마켓의 판매중 매물로 진행하는 이상형 월드컵입니다.
파일 하나로 동작하며 별도 빌드나 서버가 필요 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.
GitHub Pages로 배포하면 `https://<아이디>.github.io/<저장소>/` 로 접속됩니다.

## 데이터

| 항목 | 값 |
|---|---|
| 매물 | 263건 |
| 분류 | 트랙터 220 / 콤바인 33 / 이앙기 10 |
| 실사진 | 229건 (87%) |
| 기준일 | 2026년 9월 17일 |

판매 상태가 `ONSALE`이고 승인 상태가 `APPROVAL`인 매물만 포함되어 있습니다.
가격·연식·사용시간이 명백한 입력 오류인 4건은 제외했습니다.

- 트랙터: 300만 ~ 3억원
- 콤바인: 300만 ~ 2억원
- 이앙기: 200만 ~ 5,000만원
- 사용시간 1 ~ 20,000시간, 제작년도 1998 ~ 2026

전화번호와 유저 ID 등 개인정보 컬럼은 포함하지 않았습니다.

## 기능

- 종류 → 브랜드(복수 선택) → 연식 조건으로 후보 좁히기
- 조건에 맞는 매물 수에 따라 라운드 자동 결정 (8 / 16 / 32강)
- 가격이 비슷한 매물끼리 대진 편성
- 우승 매물 사진 갤러리 (정면 · 측면 · 후면 · 운전석)
- 유사 매물 추천 및 상세페이지 연결
- 매물 등록 CTA (UTM 포함)

## 데이터 교체

`index.html` 안의 `LISTINGS` 배열만 바꾸면 됩니다.

```js
{
  id: "d124b076",           // 매물 ID 앞 8자
  cat: "트랙터",             // 기계분류
  brand: "대동",
  model: "DXM85CF-C",
  year: 2012,
  hours: 980,
  price: 11000000,          // 원 단위
  opt: "",                  // 옵션
  impl: "로타리,로더",        // 작업기
  imgs: ["https://..."],    // 사진 URL (첫 장이 대표)
  url: "https://market.pluva.kr/open-market/{전체 ID}"
}
```

## 선택 데이터 수집

`pick()` 함수 안에 GA4 전송 자리가 주석으로 표시되어 있습니다.

```js
gtag('event', 'worldcup_pick', {
  category: '트랙터',
  round: '16강',
  winner_id: '...',
  loser_id: '...'
});
```

시작 화면의 브랜드별 우승 랭킹은 localStorage 기반이라 해당 브라우저에서만 집계됩니다.
전체 집계는 GA4 이벤트로 확인해야 합니다.

## 배포 전 확인 사항

- 판매자가 올린 사진의 2차 활용 근거 (이용약관)
- 비회원(`anonymous`) 업로드 사진의 활용 범위
- 일부 파일명에 판매자 실명이 포함되어 있어 URL로 노출될 수 있음
- 사진이 동일한 중복 매물 3쌍
- AI 생성 이미지가 매물 사진으로 등록된 1건
